下载或克隆仓库后，保留完整 `web_dashboard/dist` 目录，打开其中的 `index.html`。也可在仓库根目录执行：

```sh

```

然后访问 `http://127.0.0.1:8765`。GitHub 仓库中的 HTML 文件默认是源代码，不是已托管的网站；本次只推送文件，GitHub Pages 未开启。

## 数据口径

- 日数据唯一键为日期 + 物理台号。0G 是未观察到游玩，不自动作为负样本；缺日、缺表、计数不符均标注。
- 逐次记录逐台逐日与 BB/RB 核对。BB/RB 保留原始信号，不统一解释为初当、CZ 或连奖；逐次表没有精确出玉数值。
- 本页日内曲线来自 Anaslo 数字坐标。横轴仅为采样点序号，实际时间尚未校准；不与逐次精确对齐，也不新增 >3000 锚点标签。
- 每日最终差枚与单次开奖净上涨是不同指标。历史图按每日独立结果展示，不跨日拼接余额。
- 预测存档目标为次日最终差枚 ≥ +3000；不与单段净上涨严格 >3000 的研究目标混用。
- 概率与排名沿用邮件存档；AUC 使用对应原邮件展示概率的归档字段。页面不重新训练、不依实际结果改算概率；单类不显示数值 AUC。
- 权重是试验评分，不是概率，也不用于跨机种排序。
