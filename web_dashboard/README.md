# Daily Journal

每日记录、事件序列、曲线和历史评估的静态观察页。

指定仓库：`RoRyou/data_Crawling_Dsta`。网页由 GitHub Pages 发布，工作流不会更改仓库的访问权限。

## 名称与数据

- 类别使用固定代号，例如 `C0001`。新增类别只追加，不重新分配旧代号。
- 内部类别ID和数据字段保持稳定；页面与下载表格按所有者要求显示简短名称，版本不同的名称不合并。
- 只在 `category_labels` 发布批准的显示简称。来源链接、完整本地辞典及源数据适配代码不随本目录分发。
- 私有辞典仅保存在所有者电脑上；`.private/` 与 `.local/` 不进入提交，也不位于网页服务目录。
- 简称是公开的，不再对类别名称做匿名承诺；内部代号不是加密或权限控制。
- 历史提交与仓库其他目录未由本次更新清理，不应把当前页面的代号化当作整个仓库的历史清除。

## 查看

保留完整 `dist` 目录并打开 `dist/index.html`；或从仓库根目录执行：

```sh
python3 -m http.server 8765 --directory web_dashboard/dist --bind 127.0.0.1
```

然后访问本机的 8765 端口。

## 单对象 30 天历史

点选编号后，使用「查看 30 天累计与每日明细」进入历史区。窗口以所选数据日期为终点，含当天，严格取 30 个日历日，不使用后续日期。

- 展示已观察累计净变化、有效天数、累计观察量、正负值天数、累计曲线与 30 行每日明细。
- 累计是窗口内有效日结果的历史加总，不表示跨日保留的余额或状态，也不改变预测特征、标签或模型。
- 只累计当前类别最近一次已知换类之后的记录；更早的记录仍可查看，但标记为不纳入，避免同类别回归时混合不同安装段。
- 缺记录和无效值不填零，0 次观察不计为有效结果。没有有效结果时显示未知而不是 0。
- 曲线在无有效结果处断开；之后的值仍是已知日合计，不暗示缺失日已恢复。存在未知日期时明确标为部分合计。

## 单对象近期事件间隔分布

点选编号，点击「查看最近事件间隔分布」即可查看。窗口截至所选数据日期（含当天），可选 7 / 14 / 30 个日历日，支持全部信号、E1、E2 筛选。

- 展示间隔分档次数与占比、样本数、平均值、中位数以及 ≤100 / ≤200 步的历史占比。
- 0–1 步短间隔默认不计入主要统计，另报数量；勾选后单列计入。不把剩余记录自动称为首次事件。
- 仅使用同一编号、当前类别且当日逐次计数与日表一致的完整记录。缺日、未活动和不合格明细均不补零，最近一次已知类别更换以前不混入。
- 同一分钟先后顺序不明仍可统计无序频数，但不据此还原事件序列。原始信号不统一解释为首次或阶段成功事件，历史占比不是未来发生概率。
- 只读展示已核验的精确观察步数频数，不从图像推算，不改变模型、标签或邮件。数据随现有每日快照更新。

## 网页发布

发布地址：<https://roryou.github.io/data_Crawling_Dsta/>。首次部署成功后可访问。

- 根目录的 `.github/workflows/pages.yml` 在主分支网页文件更新、仓库变为公开或手动运行时触发。
- 先检查数据和渲染脚本，检查通过才发布；仓库仍为私有时跳过部署。
- 发布包严格限定为 `web_dashboard/dist`，不包含笔记本、历史提交、本地辞典和适配代码。
- Pages 的发布来源使用 **GitHub Actions**。可在 Actions 中手动运行 **Publish Daily Journal**。
- 这是公开网页，没有登录保护。网页发布范围不等于仓库公开范围：公开仓库的其他文件与历史提交仍可被查看。

## 数据边界

- 原始数值和统计口径不因改名而变化。每日净变化与单段增量仍是两个不同指标。
- 0 次观察不是已完成的零结果；缺记录、计数不符或身份变化明确标注。
- 曲线横轴为采样点序号，实际时间未校准；不能直接当成精确事件时间。
- 预测视图为历史存档，不依实际结果重新生成概率。AUC 沿用对应概率列，不跨目标混用。
- 试验评分不是概率，不能跨类别比较。

## 更新与验证

采集设备在本地进行导出、名称映射和检查；本仓库仅接收检查后的中性快照。不要把本地适配代码或对应辞典复制进来。

采集设备在现有采集任务成功后自动导出、检查并推送中性数据，主分支收到新快照后自动部署。工作流本身不会采集数据；重新运行也不会产生新的数据日期。采集设备须保持能运行任务并联网，电脑离线期间不保证更新。

自动推送只允许更新 `web_dashboard/dist/data/`，不会上传代码、辞典或原始文件。发现本地未提交改动、未知待推送提交、校验失败或日期/覆盖回退时停止并保留线上版本；网络失败等待下次采集成功后重试。没有实际数据变化时不重复提交。设备端状态与恢复记录仅保存在本地，不随网页发布。

```sh
python3 web_dashboard/verify_data.py
node --check web_dashboard/assets/app.js
node web_dashboard/test_frontend.mjs
```

30 天窗口、跨月/跨年/闰日、缺记录、未活动、换类回归、历史日期截止和快速切换均有自动检查；桌面浏览器已验证累计区与明细显示。移动端尚未专项验收。
