# Daily Journal

每日记录、事件序列、曲线和历史评估的静态观察页。

指定仓库：`RoRyou/data_Crawling_Dsta`。本目录不改变仓库的访问权限，也不自动发布网站。

## 名称与数据

- 类别使用固定代号，例如 `C0001`。新增类别只追加，不重新分配旧代号。
- 页面、数据文件和下载表格使用同一套中性字段。
- 原始名称、来源链接、对应关系及源数据适配代码不随本目录分发。
- 私有辞典仅保存在所有者电脑上；`.private/` 与 `.local/` 不进入提交，也不位于网页服务目录。
- 代号不是加密或权限控制。日期、对象编号与数值仍保留，不保证无法被推断。
- 历史提交与仓库其他目录未由本次更新清理，不应把当前页面的代号化当作整个仓库的历史清除。

## 查看

保留完整 `dist` 目录并打开 `dist/index.html`；或从仓库根目录执行：

```sh
python3 -m http.server 8765 --directory web_dashboard/dist --bind 127.0.0.1
```

然后访问本机的 8765 端口。仓库中的 HTML 默认以源代码显示；本次没有开启网页托管。

## 数据边界

- 原始数值和统计口径不因改名而变化。每日净变化与单段增量仍是两个不同指标。
- 0 次观察不是已完成的零结果；缺记录、计数不符或身份变化明确标注。
- 曲线横轴为采样点序号，实际时间未校准；不能直接当成精确事件时间。
- 预测视图为历史存档，不依实际结果重新生成概率。AUC 沿用对应概率列，不跨目标混用。
- 试验评分不是概率，不能跨类别比较。
