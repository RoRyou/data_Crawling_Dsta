INTERPRETATION

如何读这张表

差枚是投入与获得之差，并非总出玉。日差枚 ≥3,000 不等于某一次开奖 >3,000。

0G 是未观察到游玩；缺日不是零。换机种后按当日机种展示，历史不强行连续。

曲线存在估计误差、截顶与采样限制，不能直接当成精确逐次枚数。本页不新建锚点标签。

网页展示全部已采集的非ジャグラー机种；正式邮件的至少 6 台及 7 天成熟期筛选不变。

UPDATE PATH

每日更新方式

现有采集任务完成后，重新导出网页数据。采集设备需要保持联网、可运行任务。

本地网页更新与 GitHub 上线是两个步骤。只有配置并验证发布后，远程网页才会同步；重新打开页面可读取最新版本。

网页导出只包含白名单数据，不包含邮箱、登录状态、密钥或整个项目。
