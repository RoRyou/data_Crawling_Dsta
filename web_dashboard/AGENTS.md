# Dashboard boundaries

- Use only the user-approved repository `RoRyou/data_Crawling_Dsta` for this dashboard. Do not create another repository or push to the mistakenly created `kicona-daily-dashboard` repository.
- Preserve the repository's existing files and history; keep dashboard work inside `web_dashboard/` unless the user requests another scope.
- Do not enable GitHub Pages, change repository visibility, or delete repositories without explicit user authorization.
- Do not invoke Claude CLI, Anthropic API, or Claude sub-agents. Work with Codex and local tools.
- Never upload secrets, mail configuration, browser sessions, private contact details, or the full raw collection project. This directory contains an allowlisted static export.
- Keep final daily difference >= +3000 distinct from a single payout segment with net rise strictly >3000. Do not relabel one target as the other.
- Zero observed games, absent hit tables, mismatched unit-day counters, changed machine identity, and unknown curve timing must retain their uncertainty. Do not invent precise payout from BIG/REG rows.
